## 📋 Descripción

Una empresa de alquiler de vehículos necesita una aplicación que calcule el **total a pagar** por el alquiler de un vehículo, solicitando los siguientes datos al usuario:

- 📅 Cantidad de días de alquiler
- 💵 Precio de alquiler por día
- 👤 Tipo de cliente: **Regular** o **Preferencial**
